## [1.0.0] - 2025-01-20

### 🎉 Первый релиз

Первый публичный релиз приложения для управления роботизированной рукой Unitree D1.

### ✨ Добавлено

#### Управление
- **Управление 7 суставами** — индивидуальные слайдеры для каждого сустава руки с возможностью точного ввода значений
- **Аварийная остановка** — мгновенная остановка всех суставов по нажатию клавиши `Escape`
- **Home позиция** — быстрый возврат всех суставов в исходное положение (`Home`)
- **Автоматическое восстановление** — восстановление работы при ошибках или перегрузке моторов

#### Калибровка
- **Диалог калибровки** — настройка лимитов для каждого сустава
- **Менеджер калибровки** — сохранение и загрузка калибровочных профилей
- **Индивидуальные лимиты** — возможность установки минимальных и максимальных значений для каждого сустава

#### Позы и движения
- **Сохранение поз** — запоминание текущих положений всех суставов
- **Библиотека поз** — управление списком сохранённых поз
- **Запись движений** — запись последовательности движений в реальном времени
- **Воспроизведение** — автоматическое воспроизведение записанных движений с настраиваемой скоростью

#### Архитектура связи
- **DDS↔UDP мост** — промежуточный слой (`udp_relay`) для трансляции DDS сообщений в UDP
- **CycloneDDS** — использование открытой реализации DDS для связи с роботом
- **Автоконфигурация сети** — автоматическая настройка сетевого интерфейса

#### Кроссплатформенность
- **Linux** — полная поддержка Ubuntu 20.04+, Debian 10+, Linux Mint 20+
- **macOS** — поддержка macOS 11+ (Big Sur), включая Apple Silicon
- **Windows** — поддержка Windows 10/11 с Visual Studio 2019/2022

#### Установка
- **Автоматическая установка** — скрипты `setup.sh` и `setup.bat` для полной автоматизации
- **Установка Unitree SDK2** — автоматическое скачивание и установка официального SDK
- **Настройка сети** — автоматическая конфигурация LAN для подключения к руке

#### Интерфейс
- **Qt5 GUI** — современный графический интерфейс на Qt5
- **Статус подключения** — отображение состояния связи с роботом
- **Виджет суставов** — визуализация положения каждого сустава
- **Горячие клавиши** — `Escape`, `Home`, `Ctrl+S`, `Ctrl+O`

#### Документация
- **README на русском** — полная документация по установке и использованию
- **Решение проблем** — раздел с типичными проблемами и их решениями
- **Инструкции по сети** — подробные инструкции для всех платформ

### 🔧 Технические детали

- **Язык:** C++17
- **GUI фреймворк:** Qt5
- **Связь:** DDS (CycloneDDS) + UDP
- **Сборка:** CMake 3.10+
- **SDK:** Unitree SDK2

## [Unreleased]

### 🔧 Изменено

- `setup.sh`: пакеты больше не обновляются по умолчанию (флаг `--update`); поддержка Arch/CachyOS (pacman)
- `start.sh`: исправлено «тихое» завершение при отсутствии IP на сетевом интерфейсе (ошибка теперь выводится)

### 📝 Планируется

- Инверсная кинематика (IK) для управления положением захвата
- 3D визуализация положения руки
- Программируемые последовательности движений (скрипты)
- Поддержка нескольких рук одновременно
- WebSocket API для удалённого управления
- Интеграция с ROS2
